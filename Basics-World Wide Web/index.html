1. Internet Overview

The Internet is a vast global network that connects millions of computers and devices, enabling seamless communication and information sharing. It works on the foundation of TCP/IP protocols, which ensure reliable data transfer across diverse systems. Through the Internet, users can access services such as email, social media, online shopping, and cloud computing. It has transformed education, business, and entertainment by making resources universally accessible in real time.

Example: When a student visits the college website, the student's computer communicates with the web server through the Internet.

2. Fundamental Computer Network Concepts

A computer network is a collection of interconnected devices that share resources and exchange data efficiently. Networks are classified based on their scale — LAN (Local Area Network) for small areas, MAN (Metropolitan Area Network) for cities, and WAN (Wide Area Network) for global connections. Each device in a network is called a node, and communication occurs through links such as cables or wireless signals. Data travels in small units called packets, which contain both information and addressing details. Protocols like TCP/IP define how these packets are transmitted and received reliably. Network topology (star, bus, ring, mesh) determines how nodes are arranged and connected. Switches and routers manage data flow and direct packets to their destinations. IP addresses uniquely identify devices on the network. DNS (Domain Name System) translates human-readable names into IP addresses. Together, these elements form the backbone of the Internet, enabling seamless global communication.

  • Node: Any device connected to a network.
  • IP Address: A unique address used to identify a device.
  • Router: Connects different networks and forwards data.
  • Protocol: A set of rules used for communication.
  • HTTP/HTTPS: Protocols used for communication between browsers and web servers.
  • TCP/IP: A collection of communication protocols used by the Internet.

3. URL and its Structure

A URL (Uniform Resource Locator) is the address used to access resources on the Internet. It tells the browser where to find a webpage, image, or file.
A typical URL looks like: https://www.example.com:80/path/page.html?query=abc#section

Each part has a specific meaning:

  • Protocol: Defines how data is transferred (e.g., http, https, ftp).
  • Domain Name: The human-readable name of the website (example.com).
  • Port Number:Specifies the communication channel (default for HTTP is 80).
  • Path: Indicates the location of the resource on the server (/path/page.html).
  • Query String: Sends additional data to the server (?query=abc).
  • Fragment Identifier: Points to a specific section within the page (#section).

4. Domain Name

A domain name the human-readable web address used to identify a website, like www.kpriet.ac.in. It replaces complex IP addresses with easy-to-remember names. The DNS (Domain Name System) converts these domain names into IP addresses so browsers can locate the correct server.

Examples of Domain Extensions

  • .com - Commercial organizations
  • .edu - Educational institutions
  • .org - Organizations
  • .gov - Government organizations
  • .in - India

5. Web Browsers and Web Servers

Web Browser

A web browser is software used to access and display websites. It sends requests to web servers and displays the received webpages.

Examples: Google Chrome, Microsoft Edge, Mozilla Firefox and Safari.

Web Server

A web server is a computer or software that stores website files and provides them to clients when requested.

6. Working Principle of a Website

When a user enters a website address in a browser, several steps take place before the webpage is displayed.

Steps

  1. The user enters a URL in the web browser.
  2. The browser finds the IP address using DNS.
  3. The browser sends an HTTP/HTTPS request to the server.
  4. The web server processes the request.
  5. The server sends a response containing webpage files.
  6. The browser interprets HTML, CSS and JavaScript.
  7. The webpage is displayed to the user.

7. Client-side and Server-side Scripting

Web applications can use scripts that execute either on the user's browser or on the web server.

Feature Client-side Scripting Server-side Scripting
Executed on User's browser Web server
Common Languages JavaScript PHP, Python, Java, Node.js
Main Purpose User interface and interaction Data processing and business logic
Database Access Normally does not directly access the database Can communicate with databases
Example Form validation Login authentication
Simple example: JavaScript can check whether a student's email field is empty in the browser. A server-side program can then verify the student's login details against a database.

The Internet, computer networks, URLs, domain names, browsers and web servers are the basic building blocks of the World Wide Web. Understanding how these components communicate helps us understand how modern websites and web applications work.
